# Link preview layout / Раскладка предпросмотра ссылок

Link cards reserve their space as soon as a message appears. Opening a channel,
restoring a position in its history, or opening a personal conversation keeps
the same viewport while preview metadata and images load. A message shows up to
two cards; unavailable previews retain a clickable domain card. Titles and
descriptions are limited to two lines, and thumbnails are cropped to the card.
Preview requests still wait until the message approaches the visible area.

Карточки ссылок занимают место сразу при появлении сообщения. При открытии
канала, восстановлении места в истории и открытии личной беседы загрузка
предпросмотров и картинок сохраняет позицию просмотра. В сообщении отображаются
до двух карточек; при недоступном предпросмотре остаётся кликабельная карточка
домена. Заголовок и описание ограничены двумя строками, изображение обрезается
по размеру карточки. Запросы предпросмотра по-прежнему выполняются только при
приближении сообщения к видимой области.
